# Monthly portfolio history

The investments page presents six UTC calendar months of **estimated** investment portfolio balances. Each month includes only snapshots recorded before the start of the following month. The last known snapshot per investment is carried forward, and investments without any as-of snapshot are counted as unvalued rather than assigned an invented balance. This is not a reconstructed market valuation, synchronized bank account balance, or cashflow-adjusted investment return. Values from different investments may have different effective snapshot dates.
